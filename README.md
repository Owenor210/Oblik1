# Oblik1 💰

Особистий фінансовий облік у форматі PWA.

## Можливості

- 💵 Основна зарплата
- ⚡ Додатковий заробіток
- 📅 Календар доходів та витрат
- 🏦 Борги та їх пріоритетність
- 💳 Підписки та регулярні платежі
- 🛟 Фінансова подушка
- 📊 Статистика
- 🧮 Місячний фінансовий план
- 🔮 Симулятор погашення боргів
- 📱 Адаптація під телефон
- 🌐 Робота як PWA
- 💾 Збереження даних у браузері

## Календар

У календарі можна бачити:

- дату отримання грошей;
- джерело доходу;
- суму доходу;
- витрати;
- суму доходів за конкретний день;
- суму витрат за конкретний день.

Натискання на день відкриває детальну інформацію.

## Джерела доходу

Можна окремо записувати:

- основну зарплату;
- додатковий заробіток;
- оплату за робочі дні;
- фріланс;
- бізнес;
- інвестиції;
- подарунки;
- інші доходи.

## Борги

Для кожного боргу можна вказати:

- назву;
- суму;
- тип;
- відсоткову ставку;
- комісію;
- мінімальний платіж.

Система автоматично визначає пріоритет боргу на основі його параметрів.

## Фінансова подушка

Можна встановити:

- поточну суму;
- бажану ціль;
- прогрес накопичення.

## Дані

Дані зберігаються локально у браузері за допомогою `localStorage`.

Сайт не потребує сервера для базової роботи.

## PWA

Oblik1 можна встановити на Android як окремий застосунок.

Після встановлення сайт відкривається окремим вікном без звичайного інтерфейсу браузера.

## GitHub Pages

Проєкт розрахований на запуск у:

`/Oblik1/`

`index.html`

Стилі:

`css/style.css`

Логіка:
